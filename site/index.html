主要功能

打印这件事需要的东西都在这里，不需要再写 socket 代码。

打印位置：一条 ^LH 说清

ZPL 每份格式只有一个原点。zpl-rest 从两个层级合成它，全部按毫米处理，只取整一次。 

^LH = round((打印机基础原点 + 左/上边距 + 偏移 X/Y) × dpmm)

快速开始

Node.js

git clone https://github.com/simonzhongeng-sketch/zpl-rest.git
cd zpl-rest
npm install
npm start

然后打开 http://localhost:18420

Windows

下载 Release 里的单文件 exe 双击运行；装有企业终端防护的机器建议用便携目录包（加壳单文件可能被启发式查杀）。

# 便携包
npm run build:win:portable

MCP 接入

AI 工具直接管理标签、渲染预览、驱动打印。

{
  "mcpServers": {
    "zpl-rest": {
      "url": "http://localhost:18422/mcp"
    }
  }
}
